## 开发约定

- 分支：`main` 始终保持可运行；功能走 `feat/xxx`，实验走 `exp/xxx`，合并用 `--no-ff`。
- 提交：Conventional Commits（`feat:` `fix:` `docs:` `refactor:` `chore:`），中文正文，一次提交只做一件事。
- 换行：统一 LF，由仓库根 `.gitattributes` 约束。
